How IDP Works

A transparent look at the AI engine, data pipeline, and planning formulas that power every prediction.

🤖 The AI Prediction Engine

IDP does not use a single model. It trains three regression models on every prediction and selects the one with the highest cross-validated R² score.

Linear Regression

Assumes population grows at a constant rate per year. Best for stable, slow-growth cities.

Polynomial (Degree 2)

Captures acceleration — the rate of growth itself is increasing. Common in fast-developing cities.

Exponential Regression

Models compounding growth (log-linearised). Best for high-growth metros like Bangalore or Surat.

ℹ️ The winning model is shown on the dashboard along with its R² score. Values above 0.95 indicate very high predictive confidence.

🏗️ Infrastructure Planning Norms

⚙️ Running Locally

Step 1 — Install dependencies
cd backend
pip install -r requirements.txt
Step 2 — Start the backend (port 8000)
uvicorn main:app --reload
Step 3 — Start the frontend (port 3000)
cd frontend
python -m http.server 3000
Step 4 — Open in browser
http://localhost:3000/index.html

⚠️ Limitations (V1)

  • Predictions assume historical trends continue — they do not account for sudden policy changes, pandemics, or economic shocks.
  • Infrastructure baselines are approximated from 2021 data; real figures may differ slightly.
  • Currently covers 15 major Indian cities — smaller cities and towns are not yet supported.
  • Confidence bands are heuristic (±10/20%) — future versions will use proper Monte Carlo simulation.
  • No migration modelling yet — internal and international migration are not separated from net population growth.
🔬 V2 will add Prophet time-series forecasting, migration data, and PostgreSQL for live data updates.
