How IDP Works

A transparent look at the AI engine, data pipeline, and planning formulas that power every prediction.

🤖 The AI Prediction Engine (V2.0)

IDP trains five models simultaneously on every prediction and selects the winner by the highest cross-validated R² score. Time normalization prevents numerical overflow for long-range forecasts. Recent data (2000–2025) is weighted 2× higher than older data to capture current urbanization velocity.

Logistic Growth (S-Curve)
Best for Megacities

Models natural population plateaus using the Verhulst equation. Estimates a carrying capacity K based on density limits.

Ridge Polynomial (Degree 3)

L2-regularized to prevent extrapolation collapse. Best for cities with complex acceleration-then-slowdown trajectories.

Polynomial (Degree 2)

Captures simple acceleration. Works well for uniformly growing cities.

Exponential Regression

Compounding growth baseline. Log-linearized to handle large numbers. Best for hyper-growth metros like Bangalore.

ℹ️ The selected model and its R² score are shown on every result. Confidence bands are derived from the spread of all 5 model predictions — not a fixed percentage.

🏗️ Demographic-Aware Infrastructure Norms

A key V2.0 upgrade: infrastructure is now allocated to the correct demographic segment, not the total population. Schools go to students only (ages 5–17, 24.6% of population). Buses go only to public bus commuters — not everyone drives; modal split data (MoUD 2024) tells us that only 28% (Tier 1 metro) or 38% (Tier 2 city) of commuters actually use public buses. This prevents grossly over-estimating fleet needs.

⚙️ Running Locally

Step 1 — Install dependencies
cd backend
pip install -r requirements.txt
Step 2 — Start the backend (port 8000)
uvicorn main:app --reload
Step 3 — Start the frontend (port 3000)
cd frontend
python -m http.server 3000
Step 4 — Open in browser
http://localhost:3000/index.html

⚠️ Limitations (V1)

  • Predictions assume historical trends continue — they do not account for sudden policy changes, pandemics, or economic shocks.
  • Infrastructure baselines are approximated from 2021 data; real figures may differ slightly.
  • Currently covers 15 major Indian cities — smaller cities and towns are not yet supported.
  • Confidence bands are heuristic (±10/20%) — future versions will use proper Monte Carlo simulation.
  • No migration modelling yet — internal and international migration are not separated from net population growth.
🔬 V2 will add Prophet time-series forecasting, migration data, and PostgreSQL for live data updates.
